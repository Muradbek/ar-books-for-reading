# Арабские книги для чтения

Классические арабские тексты из «аль-Мактаба аш-Шамиля» (.htm-экспорт), переверстанные
в EPUB под электронные читалки: без сносок мухаккика и номеров печатных страниц,
с оглавлением, направлением RTL и встроенным шрифтом Amiri.

Сайт со списком книг собирается в папку `docs/` и отдаётся через GitHub Pages.

## Как добавить книгу

```sh
# 1. положить экспорт .htm в корень проекта и собрать EPUB
python tools/make_epub.py "книга.htm"

# 2. пересобрать сайт (подхватит все .epub из корня)
python tools/make_site.py

# 3. опубликовать
git add -A && git commit -m "add: название книги" && git push
```

Через минуту-другую книга появится на сайте.

## Флаги `make_epub.py`

| флаг | зачем |
|---|---|
| — | обычный экспорт: сноски и номера страниц вырезаются, أبواب берутся из `<span class="title">` |
| `--bab` | поднять أبواب из обычного текста, если издание не разметило их заголовками |
| `--nums` | начинать новый абзац с каждого номера асара («33 -») |

Принимает несколько `.htm` подряд — так собираются многотомники:

```sh
python tools/make_epub.py "том1.htm" "том2.htm" "книга.epub"
```

## Настройки сайта

Всё в шапке `tools/make_site.py`:

- `REQUEST_ENDPOINT` — куда уходит форма заявки на книгу (FormSubmit);
- `SITE_URL` — адрес сайта, чтобы после отправки возвращать на свою страницу «спасибо»;
- `CONTACT` — запасной адрес, если форма не открылась в браузере читалки.

Имена файлов в URL задаются в `slugs.txt` (иначе генерятся транслитом).

## Что где

```
tools/make_epub.py          Shamela HTML → EPUB
tools/make_site.py          EPUB + каталог «Шамили» → статический сайт (docs/)
tools/dump_shamela.py       master.db «Шамили» → shamela_catalog.json
tools/shamela_catalog.json  полный каталог: 40 разделов, ~8600 книг (коммитится)
tools/fonts/                Amiri, встраивается в каждую книгу
slugs.txt                   арабское имя файла → латинское имя в URL
docs/                       готовый сайт: index (разделы), cat/ (все книги раздела),
                            authors.html + authors/ (авторы по векам хиджры),
                            author/ (страница автора; noindex — их ~3200),
                            books.html + harf/ (все книги по буквам, без «ال»),
                            ready.html (готовые карточками), book/ (карточки готовых),
                            request.html (заявка), catalog.xml (OPDS), books/ (EPUB)
```

Главная — все 40 разделов «Шамили». Внутри раздела перечислены все его книги:
готовые (жирным, со значком «есть EPUB») ведут на карточку со скачиванием,
остальные — на форму заявки с уже подставленным названием. Готовый EPUB находит
свою строчку в каталоге по совпадению названия; если не нашёл — `make_site.py`
напишет об этом в консоль (`!! не нашёл в каталоге`).

После обновления «Шамили» каталог освежается так:

```sh
python tools/dump_shamela.py   # прочитает D:\shamela4\database\master.db
python tools/make_site.py
```

## Права

Тексты самих авторов — общественное достояние. Работа мухаккиков и издательств,
чьи издания легли в основу, принадлежит им; книги выкладываются в том же виде,
в каком распространяет их «аш-Шамиля». Просьба о снятии книги — через форму на сайте.

Шрифт Amiri — SIL Open Font License 1.1, см. `tools/fonts/README.md`.
